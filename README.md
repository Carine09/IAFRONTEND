# Studio Lumen

Site vitrine d’une photographe, en HTML et CSS natifs.

## Lancer le site

```bash
npm run dev
```

Le site s’ouvre sur http://localhost:3000. On peut aussi ouvrir `index.html` directement dans le navigateur.

## Structure

```
studio-lumen/
├── index.html
├── styles/
│   ├── tokens.css
│   └── main.css
└── components/
    └── button.css
```
